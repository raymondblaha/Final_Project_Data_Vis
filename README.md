# Final Project Data Visualization

R Shiny data visualization project exploring music data through an interactive dashboard.

Live app: https://blahablaster123.shinyapps.io/Final_Project2/

## Portfolio Context

This is an older R/Shiny coursework project. It is kept public because it demonstrates interactive dashboard development, R-based data visualization, and deployment with ShinyApps.io. It is a secondary portfolio artifact, not the main evidence for my current data science workflow.

## What This Demonstrates

- R Shiny application structure with `ui.R` and `server.R`
- Interactive data exploration
- Dashboard-style user interface design
- Public app deployment through ShinyApps.io
- Basic data visualization workflow in R

## Repository Contents

- `ui.R`: user interface definition
- `server.R`: server-side dashboard logic
- `music_data.csv`: source data used by the application
- `README.md`: project overview
